## [EN] Excel keyboard shortcuts (English as Office display language)

| Shortcut | Function / description |
|:---|:---|
| **CTRL + C** | copy |
| **CTRL + X** | cut |
| **CTRL + V** | paste |
| **CTRL + ALT + V** | open Paste Special, with these common options:<br>V — values<br>.. — formatting<br>.. — formulas<br>.. — transpose (swap rows and columns) |
| **CTRL + D** | fill down |
| **CTRL + R** | fill right |
| **CTRL + ENTER** | fill all selected cells with the value entered in the active cell |
| **ALT + ;** | after selecting cells in a filtered list, select visible cells only |
| **CTRL + Z** | undo the last action |
| **CTRL + Y** | redo the last undone action |
| **F4** | repeat the last action (such as formatting or inserting a row or column) |
| **CTRL + F3** | open the Name Manager |
| **F2** | edit the contents of the active cell |
| **CTRL + +** | insert cells, rows, or columns |
| **CTRL + -** | delete cells, rows, or columns |
| **CTRL + T** | create an Excel table from a range of data |
| **CTRL + L** | show or hide formulas |
| **CTRL + 1** | open the Format Cells dialog |
| **CTRL + ↑ / → / ↓ / ←** | move to the edge of the current data region |
| **CTRL + .** | move to the next corner of the selection or table |
| **CTRL + G** | open Go To to navigate to a cell, range, or defined name |
| **CTRL + F** | find; supports these wildcards:<br>`?` — any single character (e.g. `Amster?am`)<br>`*` — zero or more characters (e.g. `Amster*m` or `Ams*`)<br>`~?` / `~*` / `~~` — find a literal `?`, `*`, or `~` |
| **CTRL + H** | replace; supports the same wildcards as **CTRL + F** |
| **ALT + =** | insert `=SUM(…:…)` for the range above or next to the active cell |
| **Fn + Esc/FnLock** | enable Fn Lock on your laptop keyboard so you can use the function keys directly |

## [NL] Excel sneltoetsen (Nederlands als Office-weergavetaal)

| Sneltoets | Functie / uitleg |
|:---|:---|
| **CTRL + C** | kopiëren |
| **CTRL + X** | knippen |
| **CTRL + V** | plakken |
| **CTRL + ALT + V** | plakken speciaal, met als voornaamste acties:<br>W — waarden<br>M — opmaak<br>F — formules<br>T — transponeren (omdraaien rijen <> kolommen) |
| **CTRL + D** | omlaag vullen |
| **CTRL + R** | naar rechts vullen |
| **CTRL + ENTER** | selectie vullen met de waarde die in de eerste cel wordt ingegeven |
| **ALT + ;** | bij een gefilterde lijst eerst na het maken van de selectie; hiermee de-selecteer je de niet zichtbare regels |
| **CTRL + Z** | laatste actie ongedaan maken |
| **CTRL + Y** | laatste ongedaan maken actie ongedaan maken |
| **F4** | laatste (opmaak / rij / kolom) actie herhalen |
| **CTRL + F3** | 'Namen beheren' venster openen |
| **F2** | bewerk de celinhoud in de formulebalk |
| **CTRL + +** | cellen / rijen / kolommen invoegen |
| **CTRL + -** | cellen / rijen / kolommen verwijderen |
| **CTRL + L** | maak een Excel-tabel van een gegevensbereik |
| **CTRL + T** | toon / verberg formules |
| **CTRL + 1** | celeigenschappen openen |
| **CTRL + ↑ / → / ↓ / ←** | beweeg naar de eerste niet lege cel of eerste / laatste cel |
| **CTRL + .** | beweeg naar de volgende hoek van de selectie of tabel |
| **CTRL + G** | ga naar tabel / gedefinieerde naam |
| **CTRL + F** | zoeken; met als wildcards:<br>`?` — enkel karakter (bijv. `Amster?am`)<br>`*` — een of meer karakters (bijv. `Amster*m` of `Ams*`)<br>`~?` / `~*` / `~~` — zoeken op de voor wildcards gebruikte tekens |
| **CTRL + H** | vervangen; dezelfde wildcards als bij **CTRL + F** |
| **ALT + =** | voeg `=SOM(…:…)` toe voor het bereik erboven / ernaast |
| **Fn + Esc/FnLock** | zet de FnLock aan op het toetsenbord van je laptop zodat de F-toetsen direct te gebruiken zijn |
